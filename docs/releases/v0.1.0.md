# mojo-gzip v0.1.0

**Released:** 2026-10-21 · **Commit:** the one tagged v0.1.0 · **Previous:** first release

## What it does

gzip, zlib and raw deflate for Mojo, streaming or in memory, plus crc32 and adler32, through the system libz.

## Highlights

- No linker flag: libz.so.1 is loaded at run time, so `mojo run` works.
- Streaming 50 MB of output peaks at 12 MB RSS.
- Truncated, corrupt and multi-member files behave as Python's gzip does.

## Changes

First public release, no earlier version.

## Known limits

- Linux, needs libz.so.1.
- 4 GiB per in-memory call; `GzFile` streams any size.
- `GzFile` ignores bytes after the last member (like zcat); `decompress` raises on them.
