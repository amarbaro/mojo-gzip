## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.
     3 to 6 lines: what it is, who uses it, where it runs (URL/port/binary), how to start it. -->
gzip, zlib and raw deflate for Mojo, streaming or in memory, plus crc32 and adler32, through the system libz.

## Highlights

- `crc32` and `adler32` open libz once per process, not once per call.

## Changes

### Added
- Conda recipe (`recipe.yaml`).
- `examples/quickstart.mojo`, self-contained and run by the gate.
- README install and quickstart block, one example, and badges for CI, latest release and license.

### Changed
- `crc32` and `adler32` keep the libz handle in a process-wide global, opened on first call; a missing libz still returns 0.
